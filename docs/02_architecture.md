# Architecture logique proposée

1. Interface utilisateur web/mobile.
2. API backend.
3. Gestion de conversation.
4. Détection de langue.
5. NLU : intention et entités.
6. Recherche dans la base de connaissances/FAQ.
7. Réponse fondée sur les contenus validés.
8. Feedback, analytics et supervision.
9. Modules optionnels : STT/TTS et transfert vers un agent.

Architecture à confirmer avec les contraintes techniques et de sécurité de la NARSA.
