# Checklist sécurité
- [ ] Définir les données strictement nécessaires.
- [ ] Informer l'utilisateur et recueillir le consentement lorsque requis.
- [ ] Définir les rôles et droits d'accès.
- [ ] Protéger les secrets dans les variables d'environnement.
- [ ] Éviter les données personnelles dans les logs.
- [ ] Définir sauvegarde, restauration et conservation.
- [ ] Vérifier les exigences applicables, notamment la loi 09-08 et la politique NARSA.
- [ ] Faire valider l'hébergement et les flux de données.
