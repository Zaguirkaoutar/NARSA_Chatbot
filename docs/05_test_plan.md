# Plan de tests initial
- API : disponibilité et validation des entrées.
- FAQ : exactitude, source et langue de la réponse.
- NLU : performance par intention et par langue.
- Robustesse : fautes, ambiguïtés et questions inconnues.
- Conversation : transfert vers agent et feedback.
- Sécurité : authentification, autorisations et journaux.
- Charge : définir les scénarios de charge à tester.
