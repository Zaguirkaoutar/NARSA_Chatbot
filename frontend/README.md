# Frontend React — NARSA AI Assistant

Responsable : **Nawal**

## Responsabilités
- Interface conversationnelle et affichage des messages (`src/components/ChatBox.jsx`).
- FAQ interactive (`src/components/FaqSection.jsx`).
- Feedback utilisateur (`src/components/FeedbackBox.jsx`).
- Communication avec l'API FastAPI (`src/services/api.js`).

## Démarrage rapide
```bash
cd frontend
npm install
npm run dev
```
